About Me

I'm a final-year B.Tech (AI/ML) student building real backend AI systems — not toy demos. My focus is Retrieval-Augmented Generation, LLM integration, and production-style API design, most recently proven through an enterprise RAG chatbot built during my internship at a Government of India PSU. I care about systems that actually work end-to-end: retrieval that's accurate, APIs that are testable, and code that's structured for real use — not just a notebook.

Currently: completing my degree while going deeper into LLM engineering and backend AI architecture. Background: Diploma in Electronics Engineering (SBTE Bihar, 2022–2025) → B.Tech CSE (AI/ML) at CGC Jhanjeri.

Experience

AI Intern — ALIMCO (Artificial Limbs Manufacturing Corporation of India, Government of India PSU)

Developed an enterprise Retrieval-Augmented Generation (RAG) chatbot for semantic search and Q&A over assistive-device documentation
Built a fully modular FastAPI backend — loader, chunker, embedder, vector store, retriever, prompt, and LLM service layers
