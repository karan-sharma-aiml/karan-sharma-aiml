🚀 Featured Projects
⭐ ALIMCO RAG Chatbot   🏛 Government Project 🤖 Generative AI 🚀 Enterprise AI

An AI-powered Retrieval-Augmented Generation chatbot built during my internship at ALIMCO (Artificial Limbs Manufacturing Corporation of India, a Government of India PSU). The system enables semantic search and intelligent question-answering over assistive-device documentation via a fully backend REST API.

Highlights

Modular backend architecture — loader → chunker → embedder → vector store → retriever → prompt → LLM service
Embeddings via Sentence Transformers (BAAI/bge-base-en-v1.5), indexed in ChromaDB
Dual LLM generation path — Google Gemini API (cloud) and Ollama (local)
Tested end-to-end through FastAPI's Swagger UI
Evaluated across difficulty tiers: Easy 20/20, Medium 27/30, Hard 9/10, Expert 9/10

Tech: Python FastAPI Sentence Transformers ChromaDB Gemini API Ollama Prompt Engineering REST API

Repo: ALIMCO-RAG-Chatbot
